# Cadilates - Landing Page

Pre-opening landing page for Cadilates, Santa Monica's first Cadillac Reformer Pilates studio.

**Live URL:** https://launch.cadilates.com  
**Founder:** Celeste Frias  
**Instagram:** @cadilates

## Updating Spots Claimed

Open `index.html`, find `var SPOTS_CLAIMED = 0;` near the bottom, and change the number.
Commit and push - the live site updates in ~60 seconds.

## Updating Mailchimp

The form `action` attribute in `index.html` contains the Mailchimp endpoint.
See MAILCHIMP_SETUP.md for full instructions.

## Images

All images are in `/images/`. Replace files with same filename to update.
